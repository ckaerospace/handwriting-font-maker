1. Add a photo of your handwriting

Write a few lines on any paper, plain or ruled, with a dark pen, then take a photo or choose a scan. The more different letters it contains, the more complete your font will be.

or drop an image here. JPG, PNG, HEIC from iPhone usually works through the picker.

Tips for a good photo
  • Daylight or a bright lamp, no hard shadow across the page.
  • Hold the phone parallel to the page and keep the whole sheet in view. Tilt and bent corners are corrected automatically.
  • Dark pen on light paper. Write at normal size, a few full lines (a pangram works well).
  • Want to start with the text for the best coverage? Write: The quick brown fox jumps over the lazy dog. and Zwölf Boxkämpfer jagen Viktor quer über den großen Sylter Deich.

4. Your font

Install it

Windows

Open the downloaded .ttf (or .otf), click Install. Or right-click it and choose Install for all users. Restart the app you want to use it in.

macOS

Double-click the .ttf or .otf and click Install Font in Font Book. Restart open apps.

Linux

Copy the file to ~/.local/share/fonts/ and run fc-cache -f. Or open it in your font viewer and click Install.

iPhone and iPad

iOS cannot install a bare font file from the browser. You need a free font app such as AnyFont: download the .ttf, open it with that app, and follow its steps to install the profile (Settings, then General, then VPN & Device Management or Profiles). It then shows in apps that support custom fonts, such as Pages, Keynote and Word. Exact steps change between iOS versions.

Android

Android has no universal way to install a system font. Some phones (certain Samsung, Xiaomi and Huawei models) accept fonts through their theme or font settings. Everywhere else, import the .ttf into apps that allow custom fonts, for example Canva, Word, PowerPoint or a launcher that supports fonts.

Websites (WOFF)

Upload the .woff next to your page and use @font-face { font-family: "My Handwriting"; src: url(my-handwriting.woff) format("woff"); }.
